# Feature: 20261112091756-c5b6d1fd-launch-docs

## Overview

The docs catch up with the public launch. ChatGPT users get custom connection steps that work at launch and, once TCG Replay is listed in ChatGPT's Plugin Directory, the simpler directory route first. A new "What's new" page tells players what changed in each update and whether they need to refresh their assistant's connection, with refresh steps for each assistant, so new or changed tools don't leave players confused.

## Requirements

- [x] **ChatGPT custom connection steps are current**
  The ChatGPT section of the connection docs gives steps for adding TCG Replay as a custom connection that match ChatGPT's settings at the public-launch release, and says which ChatGPT plans allow a custom connection.
- [ ] **Directory route once listed**
  Once TCG Replay is approved in ChatGPT's Plugin Directory, the ChatGPT section starts with finding and connecting "TCG Replay" there, and keeps the custom connection steps as the alternative (see Constraints for timing).
- [x] **A "What's new" page**
  The website has a "What's new" page listing player-visible changes, newest first, each dated and saying whether players need to refresh their assistant's connection. Its first entry covers the public launch.
- [x] **Refresh steps for each assistant**
  The docs explain how to refresh the connection in claude.ai, ChatGPT and Claude Code so the assistant sees new or changed tools, and the "What's new" entries that need a refresh link to them.
- [x] **Easy to find**
  The "What's new" page and the refresh steps can be reached from the docs navigation, and the connection docs point to the refresh steps for when tools seem missing.
- [x] **The docs address opens the docs**
  Visiting the docs' own address, `/docs/`, shows a docs index instead of a "not found" page.

## Constraints

- The docs stay part of the playmat's own website at tcgreplay.app and ship with it; the domain move puts the site there.
- The directory route goes live only after OpenAI has approved the listing; the maintainer decides when to switch it on after that.

## Acceptance Criteria

- [ ] **Custom steps work**
  At the public-launch release, following the ChatGPT custom connection steps from an account on a plan the docs name connects TCG Replay and makes its tools available in a chat.
- [ ] **Directory steps after approval**
  After the listing is approved, the ChatGPT section's first steps find "TCG Replay" in the Plugin Directory and connect it, and the custom connection steps still follow; before approval, no page says TCG Replay is in the directory.
- [x] **What's new page**
  The "What's new" page loads from the website, lists dated entries newest first, starts with a public-launch entry, and each entry says whether a refresh is needed.
- [ ] **Refresh steps**
  The docs contain refresh steps for claude.ai, ChatGPT and Claude Code; after a release that adds or changes a tool, following them in each assistant makes the new or changed tool appear; and every "What's new" entry that needs a refresh links to them.
- [x] **Navigation**
  The docs navigation links to the "What's new" page and the refresh steps, and the connection docs link to the refresh steps.
- [x] **Docs index**
  The website's `/docs/` address returns a page listing the docs, not a 404.

## Technical Approach

- Prefer keeping "What's new" entries in one dated list in the project, so adding one per release is a small edit.
- Prefer one refresh section in the connection docs that "What's new" entries and troubleshooting text link to, rather than repeating the steps.
- The directory steps can be drafted alongside the rest and switched on by a small follow-up change when the listing is approved.

## Success Metrics

- In the first month after launch, no GitHub issue asks a ChatGPT-connection or missing-tools question that the docs already answer.
- Every release after launch that changes what players see adds a "What's new" entry.

## Non-Goals

- Changing the addresses in the docs (covered by the domain-move spec).
- The privacy and terms pages and help links (covered by the privacy, terms and disclaimer spec).
- The ChatGPT listing text (covered by the ChatGPT submission prep spec).
- Listing TCG Replay in Claude's connector directory.
