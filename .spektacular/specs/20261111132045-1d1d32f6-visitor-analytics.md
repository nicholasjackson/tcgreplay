# Feature: 20261111132045-1d1d32f6-visitor-analytics

## Overview

Once TCG Replay launches publicly, the maintainer needs to know whether anyone is using it. Visits to the public website and to the board (the signed-in page where players watch and play their games) are counted by a cookieless analytics service, so the maintainer can see how many visits there are, which pages people read, where visitors come from and what devices they use, with no cookies, no consent banner and no record of who anyone is. Counting starts only once the privacy page says so.

## Requirements

- [ ] **Website visits are counted**
  Every page view on the public website at tcgreplay.app is counted.
- [ ] **Board visits are counted, once per session**
  A player opening the board is counted as one visit to the board, however much they move around the board in that session. (The board always asks for sign-in first, so there are no signed-out board visits.)
- [ ] **The maintainer can read the numbers**
  The maintainer can see visits, page views, top pages, referrers, countries and devices for a chosen time range in the analytics dashboard.
- [ ] **Nothing identifies a visitor**
  Counting sends no Google account, email address, game or card data, and stores nothing in the visitor's browser.
- [ ] **Blocking analytics changes nothing**
  The website and the board work exactly the same when a visitor blocks analytics.
- [ ] **Only the live playmat is counted**
  Running the playmat locally or in tests adds nothing to the dashboard.
- [ ] **Privacy page comes first**
  Counting doesn't start until the privacy page describes it.

## Constraints

- Visitor analytics use Cloudflare Web Analytics, the maintainer's choice to keep the launch's tooling in one place (DNS is already at Cloudflare).
- Counting must be cookieless, so no consent banner is needed.

## Acceptance Criteria

- [ ] **Website page views appear**
  Within 30 minutes of visiting the home page and a docs page at `https://tcgreplay.app`, both pages appear in the analytics dashboard's page views.
- [ ] **One board session, one board visit**
  Within 30 minutes of signing in, opening the board at `https://tcgreplay.app/board` and moving around it (opening card zooms, switching branches), the dashboard shows that session as one visit to the board.
- [ ] **Totals, top pages and breakdowns are shown**
  Choosing the last 7 days in the dashboard shows visit and page-view totals, a top-pages list, and the referrer, country and device type of the visits.
- [ ] **No browser storage, no identity**
  In the browser's developer tools, no cookie or browser storage entry comes from analytics on the website or the board, and no analytics request contains the signed-in email address, account, game or card data.
- [ ] **Blocked analytics change nothing**
  With analytics blocked by a content blocker, the website and the board load and work normally, with no error shown to the visitor.
- [ ] **No banner**
  No consent banner or analytics prompt appears on any page.
- [ ] **Local and test runs are silent**
  Running the playmat locally and running its tests sends no analytics request, and adds nothing to the dashboard.
- [ ] **Privacy page first**
  The privacy page's description of analytics is live no later than the first counted visit.

## Technical Approach

- Prefer adding Cloudflare's analytics script once, to the page shell the website and the board share.
- Prefer supplying the site token through configuration, so a run without it (local, tests) sends nothing.
- Optionally, let the maintainer switch counting off by configuration alone, without a code change.
- The board changes views without loading new pages; check how the script counts such a page.
- If the website or board sends a content security policy, it will need to allow the analytics script and its reporting address.

## Success Metrics

- A week after launch, the maintainer can answer "how many visits did the site get, and how many board sessions, this week?" from the dashboard alone.
- The dashboard shows only tcgreplay.app traffic.

## Non-Goals

- Usage inside the board and the assistant connection (tool calls by assistant, imports, games), errors and HTTP metrics: the observability spec.
- The privacy page's wording: the privacy, terms and disclaimer spec.
- A public stats page or any numbers shown on the site.
