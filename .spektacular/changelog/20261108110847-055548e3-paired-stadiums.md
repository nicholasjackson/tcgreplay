# Paired Stadiums

## What was built

Delta Reign's Legendary Stadiums (Legendary Pyroduct, Summit and Trench) are two different prints of one name played together as one Stadium. The playmat now supports that generally, driven by a mark in card data rather than by card names.

- **Card data.** The built card-set format and the runtime card gained an optional `playedAsPair` mark. It is absent for every other card, so existing sets did not change by a byte, and `format` stays 1. The mark adds no line to a card's text: a pair-played card carries its printed pair rule in its effect text. Delta Reign's six Legendary Stadium prints (me06-094 to me06-099) are marked by recorded corrections, the set was rebuilt with `tcgreplay sets import me06`, `sets check` is clean, and a committed-data test guards the marks.
- **Game state.** The Stadium spot holds up to two cards. A move event can carry the other half (`pair`), so a pair is played, replaced or discarded in one event. The `as: "pair"` role joins a card to a lone card in the spot. The state still reads no card data, and old records replay unchanged. The board view keeps `stadium` as one object and nests the second half as `stadium.pair`.
- **Verbs and warnings.** `PlayTrainerWith(seat, actor, iid, pair)` plays two halves together. Playing one half onto a lone half of the same name and owner completes the pair, joining that half's open play action so one undo removes both. A Stadium played over a pair, or a half moved out of the spot, takes both halves. Warnings never block:
  - standing (shown while the spot holds them): a lone half, and two copies of one print;
  - once per play: a Stadium of the same name is already in play;
  - once per play: a "pair" that is not two halves of one pair-played Stadium.

  Completing a pair does not count as a second Stadium that turn.
- **Assistant.** MCP `play_trainer` takes an optional `pair_iid`, and the server instructions and the `play-game` guide explain pair play. `card_text` shows the pair rule from the card's data.
- **Board.** The board's `play_trainer` action takes `pair_iid`. The Stadium spot shows both halves: fanned on a mat, side by side on a phone, each zoomable. Dragging the second half onto a lone half completes the pair. Two board fixes came with it: clicking a Stadium with the mouse now opens its zoom (a hover rule had been moving the spot out from under the pointer), and toasts no longer block touches on the hand beneath them.
- **Importer.** The TCG Live importer recognises a pair from the log's own lines, never from the card's mark:
  - two consecutive Stadium-spot lines by the same player for the same name join as a pair;
  - one line naming the Stadium twice plays both halves;
  - two plays whose card codes name the same print are not a pair, and give a warning;
  - a replaced pair goes to the discard in one move, and its "discarded" sublines count as already done.

  **No real TCG Live log with a pair exists yet**, so this is built and tested against a clearly marked synthetic log (`testdata/logs/synthetic_2026-11-08_ledjo23_legendary-summit-pair.txt`, `"synthetic": true` in the corpus index).
- **Documentation.** The player page on playing a game, the design notes (event schema, MCP tool contract, UI, importer hazards) and the card-set guide (the mark, an example correction, the rule that a marked print needs its printed pair rule) describe pair play. The card-set guide also explains how a new format field reaches older playmats.

## Why it matters

Players and the assistant can play Delta Reign's Legendary Stadiums as the cards say, on the board and through the assistant's tools, with no hand workarounds. Because the behaviour follows a data mark, a future pair-played card needs only a correction in its set, not a program change.

## Deviations from the plan

- **Importer built on a synthetic log; real-log criterion unticked.** The plan said to build the importer against a real log, or to defer it. The user chose a made-up log. The criterion "importing the real battle log succeeds" stays unticked (accepted shortfall). **Manual follow-up:** verify against the first real TCG Live log with a Legendary Stadium pair (test plan item 3; knowledge `gotchas/stadium-pair-log-format-unverified.md`).
- **Action joining.** Joining the first half's open play needed a small hook in the game's action machinery (`actionSpec.joinOpen` in `internal/game/game.go`).
- **Stack roles on Stadium moves.** The state ignores a stack role on a Stadium move as it always did, rather than refusing it as planned, so saved games carrying one still replay.
- **Board test seed.** The two made-up Twin Peak prints start in the board test deck, not in the hand, so existing browser tests are untouched.
- **Board fixes.** The two fixes listed under Board (Stadium zoom, toasts) were not in the plan.
- **Rollout.** Playmats built before this release cannot decode the rebuilt `me06`. They keep their current catalogue but take no further card-set updates until upgraded. The hosted playmat redeploys on the same merge. This is documented in `cardsets/README.md`.
