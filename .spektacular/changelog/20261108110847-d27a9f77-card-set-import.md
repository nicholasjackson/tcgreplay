# Card-set import

## What was built

The maintainer can now build every English card set ahead of time into the project, instead of the playmat pulling cards from TCGdex on demand. The parts:

- **`tcgreplay sets import <set>`** takes a TCGdex set id (`me06`) or a decklist code (`DLR`). With `-all` it imports every English set except Pokémon TCG Pocket. The import:
  - gathers each print from TCGdex and fills TCGdex's gaps (effect text, evolves-from, regulation marks, images) from the malie.io TCG Live export; `-no-malie` builds from TCGdex alone;
  - strips HTML from card text and merges both sources into one definition per print, with TCGdex winning every field it has;
  - applies the set's hand corrections and carries the result over the previous build: new prints are added, changed text and art replace the old, prints gone upstream are kept, and other languages' wording is kept;
  - writes a readable, deterministic JSON file per set plus a machine-readable report of everything still in doubt.
- **Report items** cover source disagreements, missing effects or move names, Pokémon without attacks, Stage 1 or Stage 2 cards without evolves-from, prints without art, changed text, redundant corrections and prints gone upstream. Each item is open, corrected or acknowledged with a reason.
- **Corrections** live in a per-set file the import never writes. Each one sets any field of a print by JSON Pointer; an acknowledgement records why an item needs no change.
- **`tcgreplay sets check`** and a Go test guard the committed card data. They reject markup, missing English names, misaligned text, dangling corrections and open items.
- **A project skill, `card-set-import`**, has the coding assistant run the import, check each open item against the printed card and both sources, record corrections or acknowledgements with reasons, repeat until nothing is open, summarise the changes, and never commit.
- **The whole English catalogue is built**: 206 sets and 21,439 prints in `cardsets/`, each report with nothing open.
  - Delta Reign has its missing Trainer text, evolves-from and regulation marks, and the Legendary Stadiums carry their pair rule.
  - Scarlet & Violet, Mega Evolution and Sword & Shield sets are verified against printed cards.
  - The older sets have reprint-filled gaps, plus 196 gaps acknowledged as unverified for the maintainer.
- **Documentation**: `cardsets/README.md` covers the format, the report kinds and how to record corrections and acknowledgements, and the README's Development section links to it.

## Why it matters

Card data the playmat will use is now complete and correct before anyone plays with it, and it is kept with the code as reviewable text. Upstream gaps no longer reach players, such as Delta Reign's missing Trainer text and HTML in attack text, or TCGdex's wrong stages and Energy kinds. Language-independent facts are stored apart from English wording, so other languages can be added later. The card-set-publishing spec builds on this to serve the data to the playmat.

## Deviations from the plan

- **Validation split.** `ValidateShape` checks structure on read and before writing. `Validate` also refuses missing English text. A set with gaps still builds, so its report can list them.
- **New report kind `missing-name`.** Some old TCGdex prints have attacks or abilities with no English name. These are now a reported gap, where the first design made the set fail to build.
- **Wiring moved earlier.** Corrections and the re-import comparison were wired into the import in their own tasks, not the report task.
- **New cosmetic comparison rules.** Weakness `x2` against `×2`, square-bracket energy symbols, and `Basic {G} Energy` against `Grass Energy` no longer count as disagreements. A move one source lists as an attack and the other as an ability is recorded.
- **Basic Energy art.** `Print.Card` applies the playmat's borrowed Basic Energy art through a new `cards.EnergyArt` wrapper, so converted cards match today's playmat.
- **Goal-check shortfall on the older sets.** The user chose to fill only gaps an identical reprint covers and to acknowledge the other 196 as unverified, rather than read the printed cards. So the criterion that every card has English text for every attack, ability and effect is accepted as unmet for those cards. Search "Unverified" in `cardsets/corrections/`.
- **Empty sets.** `wp`, `sp`, `rc` and `jumbo` have no English cards on TCGdex and are kept as empty sets.
- **malie.io asked, no reply yet.** "Ask malie.io about build-time use", a person's task, was first skipped. The maintainer then asked on the malie.io Discord on 2026-11-08 about build-time reads of the export, republishing card text built from it, using its images as a fallback, how to credit malie.io, and a heads-up channel for format changes. No reply has come yet. The ask and its open status are recorded in the knowledge entry on card image sources (`learnings/card-image-sources.md`), to be updated when a reply arrives, and the task is closed. The import keeps reading malie by default until an answer says otherwise; `-no-malie` builds without it. The task's recorded goal check stays "skipped" because the workflow cannot re-open it; an independent review judged its criterion met.
- **Fixes beyond the report items.** A few Classic Collection reprints missing their Poké-Power or Poké-Body were corrected from the originals.
