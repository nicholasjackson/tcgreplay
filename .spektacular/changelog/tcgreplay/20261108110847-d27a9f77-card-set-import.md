# Card sets built into the project

The playmat's card data can now be built ahead of time and kept in the repository. `tcgreplay sets import` builds any English set, or all of them, from TCGdex and the TCG Live export into readable files, with a report of anything still in doubt. Hand corrections survive every re-import. `tcgreplay sets check` guards the result, and the coding assistant has a skill that verifies each doubtful card against its printed image. Every English set (206 sets) is now built and checked.

> Derived from project tcgreplay (local), spec/plan 20261108110847-d27a9f77-card-set-import. See the project-level record for the full feature.

## What changed in this repo

- **New package `internal/cardset`.** It holds:
  - the built-set format, with a language-independent core and per-language text, deterministic read and write, validation, and conversion to `cards.Card`;
  - uncached TCGdex and malie fetchers with timeouts and retries;
  - HTML clean-up, normalisation and the merge of both sources;
  - JSON Pointer corrections and acknowledgements;
  - the re-import comparison, the import report and the offline check;
  - `Import` and `ImportAll`.
- **`cmd/tcgreplay`.** New `sets import <set>|-all [-dir] [-no-malie]` and `sets check [<set>...]` subcommands. The playmat's own start-up and its refusal of other words are unchanged.
- **`internal/cards`.** `EnergyArt` is exported, so built cards match the playmat's borrowed Basic Energy art.
- **New `cardsets/`.** Built sets, corrections and reports for 206 English sets, plus `cardsets/README.md`. It is excluded from the container build in `.dockerignore`.
- **New project skill `skills/card-set-import/`**, the assistant's verification playbook.
- **`README.md`.** A Card sets section in Development.
- **Tests.** Table tests for every pipeline stage, fake-upstream import tests, CLI tests, and a test running the check over every committed set.

## Why

Card data is data, not code: building it ahead of time keeps it complete, reviewable and correct before players see it. Upstream gaps such as a new set's missing Trainer text, HTML in attack text, and TCGdex's wrong stages or Energy kinds are fixed once, recorded with reasons, and kept on every later import. 196 older-set gaps that no identical reprint covers are acknowledged as unverified for the maintainer to check against the printed cards.
