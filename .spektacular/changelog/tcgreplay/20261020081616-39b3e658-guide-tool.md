# Coaching guides served by the playmat

Any assistant connected to the playmat, hosted or desktop, now learns the six coaching workflows from the playmat itself, with nothing to install or upload. It is told on connect which guides exist and when to use each, can list and read them with a `guide` tool, and in clients that show server prompts (such as Claude Code) can pick a guide directly. The `install` command and the bundled tcg skills are gone. Register the playmat with your client's own tools, and delete any old tcg skill copies by hand.

> Derived from project tcgreplay (local), spec/plan 20261020081616-39b3e658-guide-tool. See the project-level record for the full feature.

## What changed in this repo

- **Guides:** the six coaching skills moved from `skills/tcg-*` to `internal/guides/` as `import-game`, `opponent-deck`, `review-game`, `replay-drill`, `before-you-move` and `numbers-drill`, each with a one-line "use when". Their text is unchanged apart from naming guides instead of skills. `internal/guides/guides.go` embeds them and provides the list and lookup.
- **MCP server (`internal/mcpserver`):**
  - A new `guide` tool lists the guides or reads one by name. It does not bind to a game, so it works even when the hosted playmat is full.
  - Each guide is also an MCP prompt.
  - The connect instructions end with a generated one-line-per-guide block.
- **Command line (`cmd/tcgreplay`):** `install` was removed. Any unknown word on the command line now fails with `unknown command` and exit 2.
- **Removed:** `skills/skills.go`, `skills/skills_test.go`, `cmd/tcgreplay/install.go` and its tests. `skills/` keeps only Spektacular's own skills.
- **Tests:** the text checks moved to `internal/guides/guides_test.go`, with new checks. The server tests cover the guide tool, prompts, instructions and the only-real-tools check. `cmd/tcgreplay` tests cover hosted-vs-desktop equality, guides while busy, and the unknown-command refusal.
- **Packaging and docs:** `.dockerignore` excludes `skills` and keeps `internal/guides` in. The design notes describe guides.

## Why

Skills had to be copied into each assistant and went stale whenever the playmat changed. Serving the guides from the binary means every player gets the current coaching on every client the moment they connect, and the text always matches the tools of the build it ships in.
