# The playmat moves to tcgreplay.app

The hosted playmat now lives at **https://tcgreplay.app**. The website, the board, the assistant connection and Google sign-in all use and show that one address. If you connected an assistant at the old address, tcgreplay.demo.gs, your assistant now tells you the playmat has moved and to reconnect at `https://tcgreplay.app/mcp`. Old website and board links forward to the same page on tcgreplay.app.

> Derived from project tcgreplay, spec/plan 20261111093353-8ff3589f-domain-move. See the project-level record for the full feature.

## What changed in this repo

- **Address in one place.** `.do/app.yaml` sets `TCGREPLAY_PUBLIC_URL` to `https://tcgreplay.app`, with tcgreplay.app as PRIMARY and tcgreplay.demo.gs as an ALIAS. It also lists `tcgreplay.demo.gs` in the new `TCGREPLAY_MOVED_FROM` setting. Its header points at the new runbook.
- **Website.**
  - `site/src/lib/facts.ts` reads the public address from `.do/app.yaml` (`loadPublicURL`). The build fails if that value is missing, is a placeholder, is not a bare https address, or does not match the PRIMARY domain. `site/astro.config.mjs` says `https://tcgreplay.app`.
  - The connect and sign-in docs, the limits page and `README.md` name tcgreplay.app. The connecting page has one marked note for old connectors.
  - The browser suite (`site/e2e/facts.spec.js`, `connect.spec.js`, `site.spec.js`) checks the facts, the note and the copy buttons. It also scans every built page and the README for a stray `demo.gs` or any `www.tcgreplay.app`.
- **Moved answer.** `internal/mcpserver/moved.go` adds `MovedText` and the `Moved` middleware, tested in `moved_test.go`. `internal/mcpserver/server.go` tolerates a server with no game manager.
- **Moved-host guard.** `cmd/tcgreplay/moved.go` adds `parseMovedHosts`, `movedGuard` and `movedMCP`, wired into `runHosted` (`cmd/tcgreplay/hosted.go`) with the `-moved-from` flag (`cmd/tcgreplay/main.go`). Tests are in `cmd/tcgreplay/hosted_moved_test.go` and `hosted_test.go`. The `serveHosted` test helper in `cardsets_test.go` uses the guard. The `Dockerfile` settings comment names `TCGREPLAY_MOVED_FROM`.
- **Docs for maintainers.** `docs/domain-move.md` is the ordered console runbook, with a check for each step and a retirement section. `TCG Review Playmat Design and Build Plan.md` describes the new address, the moved-host behaviour and the amended Host rule.

## Why

The public launch (ChatGPT listing, docs, legal pages) names the playmat's address, and a published ChatGPT plugin cannot change it later. This repo is where the address is set, served and documented. The playmat itself must answer old assistant connections, because a redirect drops the assistant's token and leaves the player with a generic failure.

## Still to do after this lands

After the merge deploys, the maintainer follows `docs/domain-move.md`:
- apply the app spec with `doctl apps update`, so `TCGREPLAY_MOVED_FROM` takes effect;
- narrow the demo.gs Cloudflare redirect rule to leave `/mcp` alone;
- update the consent-screen URLs;
- run the live checks;
- remove the old Google callback.

Until then, an assistant at the old address is still redirected and sees a generic failure.
