# Launch docs: current ChatGPT steps, refresh steps, What's new and a docs index

The website's docs are ready for the public launch. ChatGPT users get connection steps that match ChatGPT's current settings, and the docs say which ChatGPT plans allow them. Every player gets one place that explains how to refresh their assistant's connection after an update. A new "What's new" page says what changed in each release and whether a refresh is needed, and the docs' own address now opens an index of every docs page.

> Derived from project tcgreplay, spec/plan 20261112091756-c5b6d1fd-launch-docs. See the project-level record for the full feature.

## What changed in this repo

- **Docs index.** `site/src/lib/docs-pages.ts` is the one list of docs pages. The sidebar (`site/src/layouts/Docs.astro`) and the new `site/src/pages/docs/index.astro` both render it, so `/docs` and `/docs/` list every docs page with its description. The sidebar starts with "All docs".
- **Connecting page.** `site/src/content/docs/connect.md` became `site/src/pages/docs/connect.astro`, at the same address.
  - The ChatGPT section names the plans that allow a custom connection and follows OpenAI's current flow, through "Create as a plugin" and Install.
  - A new "Refresh after an update" section (`#refresh`) covers claude.ai, ChatGPT and Claude Code, and each assistant's troubleshooting line links to it.
  - The move note gained `id="moved"`.
  - The Plugin Directory steps are written in but switched off by `chatgptDirectory.listed` in the new `site/src/lib/listing.ts`.
- **What's new.** The list lives in `site/src/data/whats-new.yaml`. Its loader, `site/src/lib/whats-new.ts`, stops the build on a malformed entry. The page is `site/src/pages/docs/whats-new.astro`, and its first entry is the public launch.
- **Tests.**
  - New `site/e2e/docs-index.spec.js` and `site/e2e/whats-new.spec.js`.
  - Extended `site/e2e/connect.spec.js`: plans, refresh section and links, and the directory flag.
  - `site/e2e/site.spec.js` now fails if any page mentions the Plugin Directory while the flag is off.
- `site/src/content.config.ts`: the `showAddress` comment now notes that no Markdown page uses it.

## Why

The launch changed the playmat's address and how ChatGPT users connect, and every update that adds or changes a tool can leave an assistant with an old tool list. The website is where players learn to connect, so the fix lives here. Turning on the Plugin Directory route once OpenAI approves the listing is now a one-line change in `site/src/lib/listing.ts`, plus a What's new entry. That switch is the maintainer's deferred task.
