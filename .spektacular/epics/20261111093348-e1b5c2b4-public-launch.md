## Overview

Launch TCG Replay publicly and submit it to ChatGPT's Plugin Directory. The hosted playmat moves to its own domain, tcgreplay.app, and gains the things a public listing needs: visitor counts, diagnostics, honest privacy and terms pages with a Pokémon non-affiliation disclaimer, tool metadata and a plugin package that pass OpenAI's review, and docs that match.

The pieces:

1. **Domain move.** The site, board, MCP server and OAuth move to tcgreplay.app. tcgreplay.demo.gs keeps serving, with a notice, until connected players have moved. This comes first: a ChatGPT plugin's address cannot change after publication.
2. **Visitor analytics.** Cloudflare Web Analytics on the website and the board: cookieless, so no consent banner.
3. **Observability.** DigitalOcean Insights and alerts for HTTP, CPU, memory and restarts; structured log lines for application errors and usage events (tool calls by assistant, imports, games), with no personal data.
4. **Privacy, terms and disclaimer.** The privacy page updated for analytics and diagnostics, a new terms of service page, and a non-affiliation disclaimer and card-data attribution on the site, in the style other community tools use.
5. **ChatGPT submission prep.** Explicit readOnlyHint, destructiveHint and openWorldHint on every tool, the domain-verification challenge route, the plugin ZIP, a reviewer account with a sample game, and the review material.
6. **Docs.** Connection docs for the new domain and the Plugin Directory listing, and a note on refreshing the plugin after an update.

The Pokémon IP question is accepted as a risk: OpenAI may reject the listing, and the work is worth doing anyway.
