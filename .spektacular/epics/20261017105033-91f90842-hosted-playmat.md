## Overview

Host the tcgreplay playmat so it can be used away from the desktop. After a game, the player passes a TCG Live battle log to Claude in claude.ai (web or mobile); Claude estimates the opponent's deck, imports the game into the hosted playmat, returns a link to the board, saves the game record (transcript, both decks, seed) wherever the user keeps records (Notion for the owner, optional for others), and analyses the game on the board.

The hosted playmat runs as a single stateless Docker container: games live in memory for the session and nothing survives a restart, because a game is rebuilt deterministically from its record. Google sign-in protects it from abuse. Other people may use it, so each signed-in account gets its own game. One instance for now; multi-instance routing is out of scope. The board stays in its own browser tab (no in-chat MCP App).
